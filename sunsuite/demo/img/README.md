# תמונות SUNSUITE לדמו

שמרו כאן את קובצי התמונות של המתחמים. לאחר ההעלאה, הן יוקטנו, ידחסו ויוטמעו
בדמו (סקשני המתחמים, כרטיסי "סוגי נופש" והגלריה).

## מה להעלות (JPG או PNG, כל גודל — נדחס אוטומטית)

- `suite-1.jpg`, `suite-2.jpg` … — SUNSUITE (סוויטה, סלון, חדר שינה, חצר)
- `spa-pool.jpg`, `spa-jacuzzi.jpg`, `spa-sauna.jpg` — SUNSPA
- `tiberias-view.jpg`, `tiberias-living.jpg` — טבריה (נוף לכנרת, סלון)
- `gallery-1.jpg`, `gallery-2.jpg` … — תמונות נוספות לגלריה

אפשר גם שמות אחרים — רק ציינו איזו תמונה שייכת לאיזה מתחם.
